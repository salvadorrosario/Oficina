                                        Oficina - Gestão de Carros

        Descrição:   
     - O principal objetivo é aplicar conceitos fundamentais de programação orientada a objetos


       Estrutura do projeto:

     - Oficina.java – Classe principal, responsável pela execução do programa.

     - Carro.java – Classe que representa um carro, contendo o nome e o preço.

        Funcionalidades

    Criar objetos do tipo Carro.
    Armazenar vários carros num array.
    Percorrer o array e apresentar as informações dos carros.
    Calcular o preço total dos carros.


    Tecnologias utilizadas

    - Java
    - IntelliJ IDEA
    - Git
    - GitHub
